# Text Editors Lab: Checklist

> **The goal:** download a book from the terminal, then learn to get around it in a text editor that runs inside the terminal.

## Step 1: Download a Book with `wget`

- [ ] Open your terminal.
- [ ] Look up how to use `wget` (try `man wget`, and press **q** to quit).
- [ ] Go to [Pride and Prejudice on Project Gutenberg](https://www.gutenberg.org/ebooks/1342) and find the **Plain Text UTF-8** version.
- [ ] Copy the link to that file.
- [ ] Use `wget` in your terminal to download it.
- [ ] Use `ls` to make sure the file is there.

## Step 2: Pick Your Editor

- [ ] Choose **one** editor to learn:
  - `nano`: friendlier, with its shortcuts listed at the bottom of the screen
  - `vi`: more challenging, but very powerful once you learn it
- [ ] Find a guide or cheat sheet for your editor, like [this nano guide](https://www.geeksforgeeks.org/linux-unix/nano-text-editor-in-linux/).

## Step 3: Learn the Six Features

Practice each one on your Pride and Prejudice file until you can do it without looking it up.

- [ ] **Open** the file in your editor.
- [ ] **Save and exit.** Try making a small change first so you know your save worked.
- [ ] **Copy, cut, and paste** a line of text.
- [ ] **Go to the beginning** of the file.
- [ ] **Go to the end** of the file.
- [ ] **Search** for a word or phrase. Try searching for `Darcy`.
- [ ] Write down the keys for all six features, so you remember them for your demo.

## Step 4: Reflect and Submit

- [ ] Answer the reflection questions:
  - [ ] What is a text editor?
  - [ ] Why is it important to learn a text editor?
  - [ ] Give an example where a mouse won't be available and the terminal will be your only option.
- [ ] ✋ Demonstrate all six features to your instructor.
- [ ] ✋ Answer the reflection questions for your instructor.

## Extension (Optional)

- [ ] Create a custom keybinding for vim by editing your `.vimrc` file. For example, save and exit with **Ctrl + S**, or paste with **Ctrl + P**.
