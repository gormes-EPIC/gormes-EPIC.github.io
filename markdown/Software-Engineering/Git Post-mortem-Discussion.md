# Git Post-mortem Discussion


## Objective
1. Identify the relevance of Git and GitHub to modern software development
2. Identify effective Git troubleshooting strategies

## What to Prepare

Please be prepared to answer the discuss the following questions: 

1. What has been productive about working with Git/GitHub? What has been challenging about working with Git/GitHub?
3. What has been helpful in learning Git/GitHub so far? What resources or strategies have you used?
4. Why is Git/GitHub so important for modern software development?
5. How can you use GitHub to support your career goals?
6. What is the purpose of the commit message? What qualities should you maintain in your own commit messages?
7. What's a `.gitignore` and why is it important?
8. When working with others, why is using branches the preferred method?
9. What security risks do we need to be aware of as we continue to use GitHub?
