1. Start by creating and account and obtaining an API key for [TMDB](https://developer.themoviedb.org/docs/getting-started). Use `.env` file to store your API key.

2. Referring to [this API documentation](https://developer.themoviedb.org/reference/getting-started) and write a Python program to find the following:
    - List this week’s top 5 trending movies with their release years.
    - Given a movie title, show which streaming services carry it in the US.
    - Zendaya’s top-rated film. Find her highest-rated movie, ignoring obscure titles with only a handful of votes.
    - How many hours would it take to watch every Lord of the Rings movie back to back?
    - What’s Christopher Nolan’s average rating across every film he’s directed?
    - Which movies have both Tom Hanks and Meg Ryan appeared in?
    - Find the highest-rated episode of Breaking Bad, across all seasons.
