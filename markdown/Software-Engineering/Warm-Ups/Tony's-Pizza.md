**Instructions:** Using the following brief, create a SQL database schema including data types and constraints.

> Tony’s Pizza wants to stop using paper tickets. Customers call or walk in to place orders. The shop wants to remember each customer’s name, phone number, and address so regulars don’t have to repeat themselves. Some customers have more than one address, like home and work.

> An order is placed by one customer at a specific date and time, and is either pickup or delivery. If it’s delivery, it goes to one of the customer’s addresses.

> An order can include several pizzas. Each pizza has a size (small, medium, large) and a crust (thin, regular, deep dish). Each pizza can have any number of toppings. Toppings have a name and a price.  Tony needs to be able to keep track of how many pizzas used certain toppings, so he can schedule more ingredients to be delivered. 

> Tony also wants to know which driver delivered each delivery order. Drivers have a name and a phone number.
