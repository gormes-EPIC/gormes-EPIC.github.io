### Project Manager

**Roles and Responsibilities**
- Owns the technical direction of the project
- Reviews code and approves pull requests
- Manage automatic testing through GitHub Actions

### Interface Engineer

**Roles and Responsibilities**
- Designs and implements the game. This could be physical with a Raspberry Pi or virtual with JavaScript.
- Responsible for the correct implementation of game logic. 

### Frontend Developer

**Roles and Responsibilities**
- Create a scoreboard website that interacts with the API

### Backend Developer
**Roles and Responsibilities**
- Designs the API and backend that supports the project

### Data Architect

**Roles and Responsibilities**
- Designs and mangages the database
- Writes SQL queries for use cases
