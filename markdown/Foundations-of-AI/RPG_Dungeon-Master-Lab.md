# AI RPG Dungeon Master Lab

## Objectives
1. Explain how an autonomous agent decides what to do next based on its goals, context, and available tools.
2. Define tools, such as dice rolling or inventory tracking, that an LLM can call during a game.
3. Maintain game state across multiple turns so the agent responds consistently to player actions.
4. Test the agent with different player inputs and refine its instructions to handle unexpected or off-track behavior.
