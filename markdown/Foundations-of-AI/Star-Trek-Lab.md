# Star Trek Lab

## Objectives
1. Engineer and refine a system prompt to produce script output in a specific style without fine-tuning.
2. Prepare a domain-specific training dataset in the format required for fine-tuning.
3. Fine-tune a language model to generate text in the style of Star Trek scripts.
4. Compare prompted and fine-tuned results using defined criteria, and explain the tradeoffs in cost, effort, and quality.
