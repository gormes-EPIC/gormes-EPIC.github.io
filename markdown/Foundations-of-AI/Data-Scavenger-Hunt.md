# Data Scavenger Hunt

## Objectives
- Manipulate data in Python using `pandas` library
- Calculate basic statistics and aggregations using data


## Your Task

1. Download the [Mini Formula 1 Dataset]() from GitHub
2. Create a new Jupyter Notebook file. Then use `pandas` to create a database for the CSV files. 
[Original Formula 1 Race Data](https://www.kaggle.com/datasets/jtrotman/formula-1-race-data)
