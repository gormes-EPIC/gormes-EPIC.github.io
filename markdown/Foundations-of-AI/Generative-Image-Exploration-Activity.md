# Generative Image Exploration Activity

## Objectives
1. Explain how a GAN uses a generator and a discriminator that compete to produce realistic images.
2. Explain how a diffusion model creates an image by gradually removing noise.
3. Generate images with pretrained GAN and diffusion models using the same or similar inputs.
4. Compare the quality, variety, and control of each model’s output and justify which fits a given use case.
